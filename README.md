# Konspekt

Приложение для превращения аудиозаписей уроков в редактируемые конспекты, разложенные по предметам.

## MVP

1. Создать предмет.
2. Загрузить аудиозапись.
3. Получить расшифровку и структурированный конспект.
4. Отредактировать и сохранить результат.
5. Найти конспект по предмету или поиску.

## Команда

- **Арсений — приложение и хранение данных:** интерфейс, библиотека предметов/конспектов, загрузка аудио, локальное хранение, поиск и редактирование.
- **Участник 2 — обработка и ИИ:** распознавание речи, подготовка длинного аудио, генерация конспекта, статусы задач и обработка ошибок.

## Прототип распознавания речи

Сейчас есть CLI-прототип на Python, использующий OpenAI Audio Transcriptions API. Он принимает один аудиофайл до 25 MB и печатает распознанный текст.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

Добавьте ключ в `.env`, затем загрузите переменные в текущую оболочку (`set -a; source .env; set +a`). Не коммитьте `.env`.

```bash
transcribe-lesson путь/к/уроку.m4a --language ru
```

По умолчанию выбран `gpt-transcribe`; модель можно поменять через `OPENAI_TRANSCRIPTION_MODEL`. При вызове файла его аудиоданные передаются OpenAI для распознавания. Не используйте записи без разрешения участников. Файлы больше 25 MB пока нужно сжать или разделить вручную.
