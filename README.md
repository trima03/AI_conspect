# AIKonspekt

Приложение для аудиозаписей занятий и расшифровок по предметам.

## Что работает

- Интерфейс PySide6: главная страница, добавление лекции, список всех лекций.
- Создание предмета при добавлении лекции.
- Загрузка аудиофайла или запись с выбранного микрофона с таймером и индикатором громкости.
- Локальное распознавание русской речи Whisper, без ключа API и оплаты за запросы.
- Сохранение расшифровки в SQLite, повторная обработка, исправление текста и экспорт TXT.
- Обработка в фоне, отмена между фрагментами, понятные ошибки и сохранение исходного аудио.

Генерация структурированного конспекта, поиск и отдельный экран управления предметами — следующие этапы.
«Готово» сейчас означает готовность расшифровки.

## Запуск на Mac с Apple Silicon

В Terminal или терминале PyCharm:

```bash
cd /Users/tim/PycharmProjects/AI_conspect-git
source .venv/bin/activate
python -m pip install -e ".[desktop,mac]"
python run_app.py
```

При установке с нуля сначала создайте окружение: `python3 -m venv .venv`.
В PyCharm выберите интерпретатор `.venv/bin/python`, затем запустите `run_app.py`
или общую конфигурацию **AIKonspekt** из папки `.run`.

FFmpeg поставляется через `imageio-ffmpeg`; Homebrew и отдельная настройка PATH
для команд проекта не нужны. Файл `.env` и OPENAI_API_KEY больше не используются.
MLX требует Mac с Apple Silicon и macOS 14+.

## Как записать лекцию

1. Нажмите «+ Добавить лекцию».
2. Выберите предмет или нажмите «+ Предмет», заполните название.
3. Выберите модель: **Small** точнее, **Tiny** быстрее и подходит для проверки запуска.
4. Нажмите «Записать с микрофона». Если macOS запросит доступ, разрешите микрофон
   для запускающей программы — PyCharm или Terminal.
5. Нажмите «Остановить и распознать». Аудио сохраняется, затем начинается расшифровка.
6. Прочитайте текст, исправьте при необходимости и нажмите «Сохранить правки».

Для готовой записи используйте «Загрузить аудиофайл» → «Распознать».
Результат можно открыть повторно на главной странице или в «Все лекции».

Модели скачиваются с Hugging Face при первом запуске (Small требует несколько
сотен МБ свободного места). После скачивания можно работать без интернета.
Аудио и текст остаются на компьютере. На первом запуске фрагмент 1 может долго
не меняться — в это время загружаются веса модели.

## Команды без интерфейса

```bash
# Локально распознать файл и сохранить новый TXT
transcribe-lesson test1.m4a --model tiny --output transcripts/test1.txt

# Более точная модель, подсказка с терминами
transcribe-lesson lesson.m4a --model small --language ru --prompt "Производная, интеграл, Лейбниц"

# Микрофоны и запись на 30 секунд
record-lesson --devices
record-lesson --seconds 30

# Без --seconds запись останавливается по Enter или Ctrl+C
record-lesson

# Распознать существующий урок и сохранить текст в базе
transcribe-lesson --lesson-id 1 --model small
```

`--output` не перезаписывает существующий файл. Для повторного запуска выберите новое имя.
Сторонняя команда `mlx_whisper` не является точкой входа проекта; используйте
`transcribe-lesson`, чтобы автоматически находить FFmpeg и обрабатывать ошибки.

## Windows, Linux и Intel Mac

Установите `python -m pip install -e ".[desktop,cpu]"`. Приложение автоматически
выберет CPU-движок faster-whisper. На Apple Silicon его можно использовать через
CLI с `--backend cpu`. На Linux для записи может дополнительно понадобиться
системная библиотека PortAudio. Проверка на этом этапе выполнена на Apple Silicon;
другие платформы требуют проверки на реальном устройстве.

## Данные и ограничения

- База: `data/konspekt.db`; копии импортированного аудио: `data/audio/`.
- Исходные записи микрофона: `data/recordings/`. После привязки к уроку остаются
  исходник и копия: при ошибке базы или распознавания запись не теряется.
- Изолированная папка данных: `python run_app.py --data-dir /tmp/konspekt-demo`.
- Локальная обработка: до **2 ГБ / 4 часов**, нормализация в mono PCM 16 кГц,
  распознавание частями по 2 минуты. На границах фрагментов возможны ошибки слов.
- Нужна свободная память для модели и место для временного WAV (до ~461 МБ на 4 часа).
- Отмена ожидает завершения текущего фрагмента или скачивания модели; окно остаётся открытым.
- При аварийном завершении откройте урок и нажмите «Сбросить зависшую обработку»,
  убедившись, что другой экземпляр приложения не обрабатывает этот урок.
- При ошибке повторного распознавания прежний текст сохраняется. При успешной
  замене текста старый конспект сбрасывается, поскольку он мог устареть.
- `lesson_audio` и `audio` сохраняют прежний лимит 25 МБ по умолчанию для
  совместимости. Новый интерфейс явно передаёт локальный лимит 2 ГБ.

`data/`, `recordings/`, `transcripts/`, `.env`, `.venv/` и тестовые записи
игнорируются Git. Экспортированные в другие папки реальные тексты не коммитьте.

## Для Арсения: интерфейс модулей

```python
from threading import Event
from konspekt.recording import record_audio
from konspekt.pipeline import transcribe_lesson

# Вызывать в фоновом потоке. Event.set() останавливает и сохраняет запись.
path = record_audio(Event(), duration_seconds=10)
# Урок уже создан через lesson_audio.create_lesson_with_audio(...).
lesson = transcribe_lesson(lesson_id=1, model="small")
print(lesson.transcript)
```

`transcription.transcribe_audio()` возвращает `TranscriptionResult` с текстом,
моделью, языком и сегментами с временем. `pipeline.transcribe_lesson()` ведёт
статусы `queued → processing → completed/failed` и сохраняет текст в хранилище.
Отмена возвращает урок в очередь. `ui/audio_dialog.py` связывает запись,
загрузку файлов и обработку с существующим интерфейсом.

## Проверки

```bash
python check_storage.py
python check_audio.py
python check_lesson_audio.py
python check_create_lesson.py
python check_ui_logic.py
python -m unittest discover -s tests -v
```

Проверки используют временную базу, искусственный микрофон и подмену модели;
реальное аудио пользователя и его база не изменяются. FFmpeg проверяется реальным
декодированием WAV. Для ручной проверки микрофона запишите 10–20 секунд знакомого
текста и сравните расшифровку со сказанным.
