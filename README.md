# AIKonspekt

Приложение для аудиозаписей занятий и расшифровок по предметам.

[Руководство](docs/index.md) · [Выпуски](https://github.com/trima03/AI_conspect/releases) · [Сообщить об ошибке](https://github.com/trima03/AI_conspect/issues/new)

## Что работает

- Интерфейс PySide6: главная страница, предметы с лекциями, добавление лекции, список всех лекций, записи и корзина.
- Создание предмета при добавлении лекции.
- Загрузка аудиофайла или запись с выбранного микрофона с таймером и индикатором громкости.
- Локальное распознавание русской речи Whisper, без ключа API и оплаты за запросы.
- Сохранение расшифровки в SQLite, повторная обработка, исправление текста и экспорт TXT.
- ИИ-конспект на русском языке: краткий или подробный, редактирование, сохранение, экспорт Markdown.
- Обработка в фоне, отмена между фрагментами, понятные ошибки и сохранение исходного аудио.

Локальное создание структурированного ИИ-конспекта и поиск по библиотеке уже работают.
«Готово» означает готовность расшифровки. Состояние конспекта показывается отдельно на его вкладке.

## Если в аудитории шумно

В окне лекции включите «Шумная аудитория: снизить фоновый шум», затем запустите распознавание. Программа обработает временную копию аудио, а исходный файл сохранится. Режим уменьшает низкочастотный гул и применяет умеренное подавление постоянного шума через уже установленный FFmpeg. Новые модели или доступ к облаку для этого не нужны.

Режим по умолчанию выключен, поскольку фильтрация может ухудшить тихую речь. Чтобы сравнить варианты, экспортируйте прежнюю расшифровку в TXT перед повторным распознаванием. Успешный новый запуск заменяет текст лекции, как и обычное повторное распознавание.

Эта обработка не отделяет преподавателя от других говорящих людей и не восстанавливает слова, которых не слышно на записи. Проверьте несколько фраз из реальной лекции в обоих режимах. Если преподаватель далеко, приблизьте микрофон к нему; в поле «Подсказка» можно указать термины занятия. Для проверки качества используйте Turbo, а не Tiny.

Через терминал тот же режим включается флагом `--reduce-noise`:

```bash
transcribe-lesson lecture.m4a --model turbo --reduce-noise --output transcripts/lecture-clean.txt
```

Параметры фильтра находятся в `transcription.CLASSROOM_FILTER`. Механика подавления шума описана в [документации FFmpeg](https://ffmpeg.org/ffmpeg-filters.html#afftdn). Улучшение распознавания именно вашей записи пока не проверялось.

## Поиск по библиотеке

Откройте «Поиск» или «Все лекции» и введите слова из нужного занятия. Поиск проверяет название и предмет, а также содержимое расшифровки и сохранённого конспекта. Например, запрос `физика ускорение` найдёт занятие по физике, в тексте которого есть слово «ускорение».

Все слова запроса должны встретиться в лекции, при этом они могут находиться в разных полях. Регистр букв не влияет на результат, а `ё` и `е` считаются одинаковыми. Проценты и подчёркивания ищутся как обычные символы. Поиск по формам слова или опечаткам пока не поддерживается.

Выберите предмет или состояние обработки, если нужно сузить результаты. Под названием показывается фрагмент текста с совпадением, а кнопка «Открыть» ведёт к нужной лекции. «Сбросить поиск» очищает запрос и оба фильтра. В открытом разделе можно нажать Cmd+F на Mac или Ctrl+F на других платформах.

Корзина в результаты не попадает, восстановленные лекции снова доступны для поиска. Изменения текста видны сразу после сохранения, отдельного индекса нет. Поиск выполняется на компьютере. Запрос ограничен 200 символами; если найдено больше 100 лекций, интерфейс показывает их общее число и предлагает уточнить запрос.

## Запуск на Mac с Apple Silicon

В Terminal или терминале PyCharm:

```bash
git clone https://github.com/trima03/AI_conspect.git
cd AI_conspect
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[desktop,mac,notes-mac]"
python run_app.py
```

В PyCharm выберите интерпретатор `.venv/bin/python`, затем запустите `run_app.py`
или общую конфигурацию **AIKonspekt** из папки `.run`.

FFmpeg поставляется через `imageio-ffmpeg`; Homebrew и отдельная настройка PATH
для команд проекта не нужны. Файл `.env` и OPENAI_API_KEY больше не используются.
MLX требует Mac с Apple Silicon и macOS 14+.

## Как записать лекцию

1. Нажмите «+ Добавить лекцию».
2. Выберите предмет или нажмите «+ Предмет», заполните название.
3. По умолчанию выбрана **Large v3 Turbo** — точное локальное распознавание. **Small** экономит память, **Tiny** подходит только для проверки запуска.
4. Нажмите «Записать с микрофона». Если macOS запросит доступ, разрешите микрофон
   для запускающей программы — PyCharm или Terminal.
5. Нажмите «Остановить и распознать». Аудио сохраняется, затем начинается расшифровка.
6. Прочитайте текст, исправьте при необходимости и нажмите «Сохранить лекцию».

Для готовой записи используйте «Загрузить аудиофайл» → «Распознать».
Результат можно открыть повторно на главной странице или в «Все лекции».
Если текст уже есть, вставьте его на вкладке «Расшифровка» или нажмите
«Импорт расшифровки TXT», выберите предмет и сохраните лекцию без аудио.

Модели скачиваются с Hugging Face при первом запуске. Для Turbo на Apple Silicon
используется компактная версия 4 bit (~464 МБ): https://huggingface.co/mlx-community/whisper-large-v3-turbo-4bit.
Она проверена с mlx-whisper 0.4.3; приложение адаптирует имя файла весов локально.
Тема и предмет автоматически используются как контекст, а пользовательская подсказка
позволяет добавить сложные термины. Режим с случайной генерацией отключён. После скачивания можно работать без интернета.
Аудио и текст остаются на компьютере. На первом запуске фрагмент 1 может долго
не меняться — в это время загружаются веса модели.

## Бесплатные ИИ-конспекты

На Mac с Apple Silicon конспекты создаёт **Qwen3 4B Instruct 2507, 4 bit** через
MLX-LM. Подписка, API-ключ и оплата за запросы не нужны. Модель (~2,3 ГБ) скачивается
один раз; затем работает без интернета. Расшифровка не отправляется в сеть.
Используется зафиксированная версия весов, без выполнения кода из репозитория модели.

1. Откройте лекцию и проверьте текст на вкладке «Расшифровка».
2. Откройте вкладку «Конспект», выберите краткий или подробный режим.
3. Нажмите «Создать ИИ-конспект». Текущая расшифровка сначала сохраняется.
4. После генерации конспект автоматически сохраняется в лекции. Его можно
   исправить прямо в редакторе и нажать «Сохранить конспект».
5. «Экспорт конспекта» сохраняет Markdown (или выбранный текстовый файл).

Флажок «Создать ИИ-конспект после распознавания» запускает полный сценарий
аудио → расшифровка → конспект. Он включается по желанию, чтобы отдельно проверить
распознанные формулы, фамилии и даты до создания конспекта.

Длинный текст разбивается по числу токенов; все части обрабатываются, затем
их тезисы объединяются в цельный документ. Предел источника — миллион символов.
Это сжатый конспект: для буквальной сверки сохранена отдельная расшифровка.
Генерация работает в фоне. Отмена сохраняет предыдущий конспект; если текст
изменился во время обработки, результат по старому источнику не будет сохранён.
Оборванный по лимиту ответ не принимается за законченный конспект.

В конспект включаются положения, определения, формулы, даты и примеры, если они
содержатся в источнике. Пустые разделы могут пропускаться. ИИ всё равно способен
ошибаться: сверьте факты и формулы с записью. Исправление расшифровки сбрасывает
устаревший конспект; его нужно создать заново.

Кэш модели: `~/.cache/konspekt/notes-http`. Загрузка весов идёт по HTTPS в
отдельном процессе, её можно отменить и продолжить при следующем запуске.
Для работы проверена конфигурация Apple Silicon / 16 ГБ. На других платформах
распознавание остаётся доступным, а модуль конспектов сообщает о поддержке Mac.

```bash
# Конспект существующего урока сохраняется в базе
summarize-lesson --lesson-id 1 --style detailed

# Конспект по текстовому файлу без аудио
summarize-lesson transcripts/lesson.txt --title "Законы Ньютона" --subject "Физика" --output transcripts/notes.md
```

Техническое описание: `notes.py` — модель, разбиение и сборка; `notes_model.py` —
загрузка весов; `pipeline.summarize_lesson()` — согласованное сохранение результата
в `Lesson.summary`; `notes_state` — состояние и связь с версией источника.
Обзор всех 21 коммитов перед этой задачей находится в `docs/COMMIT_REVIEW.md`.

## Предметы, записи и удаление

«Предметы» показывает лекции выбранного предмета, включая записи ещё без текста.
Кнопка «Переименовать» меняет название выбранного предмета, сохраняя его лекции.
Через «+ Лекция в этом предмете» предмет уже выбран в форме. Чтобы сохранить аудио
без распознавания, нажмите «Сохранить лекцию». В окне существующей лекции можно
изменить предмет или название и сохранить.

- «Удалить» на главной, в предметах и списке лекций перемещает лекцию с её аудио в корзину.
- «Удалить аудио» в окне лекции оставляет текст и позволяет загрузить/записать другое аудио.
- «Записи» показывает исходные записи микрофона, в том числе после прерванной обработки.
  Несвязанную запись можно прослушать, добавить в предмет или удалить. Связанная
  удаляется из окна её лекции.
- «Корзина» восстанавливает лекцию, аудио или запись. Удаление обратимо; корзина
  продолжает занимать место на диске и сама автоматически не очищается.

Удаляются только файлы из `data/audio` и `data/recordings`; исходные импортированные
файлы пользователя вне этих папок сохраняются. Символические ссылки не удаляются.
Если запись нужна нескольким лекциям, она остаётся доступной остальным. Обработка
и удаление одной лекции одновременно не допускаются. Восстановление не заменяет
новый файл или новое прикреплённое аудио. При наличии связанных записей в корзине
приложение предложит сначала восстановить связанную лекцию.

База старых версий обновляется при запуске: добавляются поля удаления и ссылки на
исходную запись и таблица корзины. Существующие лекции, текст и предметы сохраняются.

## Команды без интерфейса

```bash
# Локально распознать файл и сохранить новый TXT
transcribe-lesson test1.m4a --model turbo --output transcripts/test1.txt

# Более точная модель, подсказка с терминами
transcribe-lesson lesson.m4a --model turbo --language ru --prompt "Производная, интеграл, Лейбниц"

# Микрофоны и запись на 30 секунд
record-lesson --devices
record-lesson --seconds 30

# Без --seconds запись останавливается по Enter или Ctrl+C
record-lesson

# Распознать существующий урок и сохранить текст в базе
transcribe-lesson --lesson-id 1 --model turbo
```

`--output` не перезаписывает существующий файл. Для повторного запуска выберите новое имя.
Сторонняя команда `mlx_whisper` не является точкой входа проекта; используйте
`transcribe-lesson`, чтобы автоматически находить FFmpeg и обрабатывать ошибки.

## Windows, Linux и Intel Mac

Установите `python -m pip install -e ".[desktop,cpu]"`. Приложение автоматически
выберет CPU-движок faster-whisper. На Apple Silicon его можно использовать через
CLI с `--backend cpu`. На Linux для записи может дополнительно понадобиться
системная библиотека PortAudio. Проверка на этом этапе выполнена на Apple Silicon;
другие платформы требуют проверки на реальном устройстве.

## Данные и ограничения

- База: `data/konspekt.db`; копии импортированного аудио: `data/audio/`.
- Исходные записи микрофона: `data/recordings/`. После привязки к уроку остаются
  исходник и копия: при ошибке базы или распознавания запись не теряется.
- Изолированная папка данных: `python run_app.py --data-dir /tmp/konspekt-demo`.
- Локальная обработка: до **2 ГБ / 4 часов**, нормализация в mono PCM 16 кГц,
  распознавание частями до 2 минут. Границы по возможности выбираются в паузах,
  а предыдущий текст передаётся как контекст следующего фрагмента.
- Нужна свободная память для модели и место для временного WAV (до ~461 МБ на 4 часа).
- Отмена ожидает завершения текущего фрагмента или скачивания модели; окно остаётся открытым.
- При аварийном завершении откройте урок и нажмите «Сбросить зависшую обработку»,
  убедившись, что другой экземпляр приложения не обрабатывает этот урок.
- При ошибке повторного распознавания прежний текст сохраняется. При успешной
  замене текста старый конспект сбрасывается, поскольку он мог устареть.
- `lesson_audio` и `audio` сохраняют прежний лимит 25 МБ по умолчанию для
  совместимости. Новый интерфейс явно передаёт локальный лимит 2 ГБ.

`data/`, `recordings/`, `transcripts/`, `.env`, `.venv/` и тестовые записи
игнорируются Git. Экспортированные в другие папки реальные тексты не коммитьте.

## Для Арсения: интерфейс модулей

```python
from threading import Event
from konspekt.recording import record_audio
from konspekt.pipeline import transcribe_lesson

# Вызывать в фоновом потоке. Event.set() останавливает и сохраняет запись.
path = record_audio(Event(), duration_seconds=10)
# Урок уже создан через lesson_audio.create_lesson_with_audio(...).
lesson = transcribe_lesson(lesson_id=1, model="turbo")
print(lesson.transcript)
```

`transcription.transcribe_audio()` возвращает `TranscriptionResult` с текстом,
моделью, языком и сегментами с временем. `pipeline.transcribe_lesson()` ведёт
статусы `queued → processing → completed/failed` и сохраняет текст в хранилище.
Отмена возвращает урок в очередь. `ui/audio_dialog.py` связывает запись,
загрузку файлов и обработку с существующим интерфейсом.

## Проверки

```bash
python check_storage.py
python check_audio.py
python check_lesson_audio.py
python check_create_lesson.py
python check_ui_logic.py
python -m unittest discover -s tests -v
```

Проверки используют временную базу, искусственный микрофон и подмену модели;
реальное аудио пользователя и его база не изменяются. FFmpeg проверяется реальным
декодированием WAV. Для ручной проверки микрофона запишите 10–20 секунд знакомого
текста и сравните расшифровку со сказанным.
