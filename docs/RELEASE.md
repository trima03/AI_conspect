# AIKonspekt 0.1.0

Настольный выпуск для работы с лекциями. Локальный Whisper распознаёт аудио, а на Mac с Apple Silicon локальная модель Qwen создаёт конспект. Готовый текст можно импортировать из TXT или вставить в редактор без аудио.

Поиск охватывает названия, предметы и тексты лекций. Предметы можно переименовывать, а лекции возвращать из корзины. При повторном распознавании с тем же результатом лекция теперь выходит из состояния обработки.

Выпуск содержит исходники в ZIP и TAR.GZ. Порядок установки и требования описаны в [руководстве](https://github.com/trima03/AI_conspect/blob/main/docs/index.md). Веса моделей скачиваются отдельно при первом использовании.
