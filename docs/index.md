# AIKonspekt

Настольное приложение для учёбы. Оно сохраняет занятия по предметам, распознаёт запись и на поддерживаемом Mac составляет конспект. Текст, аудио и база хранятся на компьютере.

## Установка на Mac с Apple Silicon

Скачайте исходники со [страницы выпусков](https://github.com/trima03/AI_conspect/releases) или склонируйте [репозиторий](https://github.com/trima03/AI_conspect). Откройте папку проекта в терминале и выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[desktop,mac,notes-mac]'
python run_app.py
```

Для MLX нужен Mac с Apple Silicon и macOS 14 или новее. Подробности установки, включая распознавание на CPU, есть в [README](https://github.com/trima03/AI_conspect#readme). Генерация конспектов в этом выпуске поддерживается на Apple Silicon. При первом запуске каждой модели нужен интернет для скачивания весов; ключ API не нужен.

## Работа с лекциями

Откройте «Добавить лекцию», выберите предмет и введите название. Можно записать звук с микрофона, открыть аудиофайл или импортировать готовую расшифровку в TXT (UTF-8). Готовый текст можно также вставить в редактор и сохранить лекцию без аудио.

После распознавания проверьте текст, особенно числа и специальные термины. На вкладке «Конспект» выберите краткий или подробный вариант и нажмите «Создать ИИ-конспект». Результат сохранится в лекции. Его можно отредактировать и экспортировать в Markdown. ИИ может ошибаться, поэтому формулы и факты лучше сверить с источником.

Через «Поиск» можно найти лекцию по названию, предмету, расшифровке или конспекту. В разделе «Предметы» можно переименовать выбранный предмет. Удалённые через интерфейс лекции можно вернуть из корзины.

## Если возникла проблема

Если микрофон недоступен, разрешите доступ программе, из которой запускаете приложение, в настройках конфиденциальности macOS. Если модель не скачивается, проверьте соединение и повторите операцию. Если после аварийного закрытия статус остался «Обрабатывается», сбросьте его в окне лекции, предварительно убедившись, что другая копия приложения её не обрабатывает.

Перед переносом или обновлением закройте приложение и сохраните копию папки данных. Для запуска из исходников по умолчанию используется папка `data` в проекте. При заданной переменной `KONSPEKT_DATA_DIR` используется указанный в ней каталог; путь к аудио в базе может быть абсолютным.

Если ошибка повторяется, [создайте задачу](https://github.com/trima03/AI_conspect/issues/new). Укажите версию приложения, ОС и шаги, на которых видите проблему. Приватное аудио и полную расшифровку прикладывать не нужно.
