## Выводы для добавления конспектов

- Функции записи, бесплатного ASR, предметов и корзины уже входят в main. Новый
  модуль конспектов добавляется поверх них и оформления Dark Pro.
- Поле `Lesson.summary` предусмотрено в схеме, но до этой задачи не существовали
  ни генератор, ни отдельный статус конспекта, ни интерфейс его создания.
- Статус completed ранее означал готовую расшифровку. Поэтому для конспектов
  добавлена отдельная таблица notes_state: этап, ошибка, модель, хеш источника,
  идентификатор задачи. Временный общий processing блокирует удаление и повторный
  запуск на той же лекции.
- Конспект сохраняется только для той версии расшифровки, по которой он создан.
  Правка источника сбрасывает устаревший конспект; неудачная повторная генерация
  не затирает прежний результат. Отмена, смена источника и сброс задачи проверяются.
- Локальные модели не требуют облачного API-ключа. Загрузка весов — отдельное
  сетевое действие; текст и аудио остаются на компьютере.

## Проверки и границы обзора

Проверены существующие check_storage, check_audio, check_lesson_audio,
check_create_lesson, check_ui_logic и check_ui_theme. Новые регрессионные тесты
покрывают сохранение, отмену, устаревшие задачи, длинный текст, UI и экспорт.
Всего прошли 55 автоматических тестов. Отдельно проверена настоящая модель
Qwen3 4B Instruct 2507 (4 bit) на Apple Silicon / 16 ГБ: создание через фоновую
задачу AudioDialog, сохранение в SQLite и отображение Markdown. Проверка выполнялась
с HF_HUB_OFFLINE=1 после скачивания и проверки SHA256 весов. На короткой лекции
по второму закону Ньютона сохранены F = m * a, пример 3 кг × 2 м/с² = 6 Н и
отметка об отсутствии определения инерциальной системы в источнике. Расшифровка
осталась неизменной. Это проверка рабочего сценария, а не оценка качества на
всех предметах и длинных лекциях; длинный текст отдельно покрыт тестами алгоритма.

Ограничения: ИИ может ошибаться, особенно при плохой расшифровке; конспект требует
сверки. Поиск остаётся отдельной будущей задачей. Корзина сохраняет файлы на диске
для восстановления. Локальные ИИ-конспекты этой версии проверяются на Apple Silicon;
проверки на Windows/Intel в эту задачу не входят.

Практическое замечание к аудиокоммитам: для старых записей без recording_path
модуль library сопоставляет исходник и копию по SHA256. На больших файлах это
может замедлять обновление раздела записей; полезная отдельная оптимизация —
сохранить найденные связи при миграции или выполнять проверку в фоне.
