# Разработка AIKonspekt

Инструкции для пользователя находятся в [руководстве](index.md) и [README](../README.md).

Приложение хранит предметы и лекции в SQLite. Основная запись `Lesson` содержит `id`, `subject_id`, `title`, `audio_path`, `status`, `transcript`, `summary`, `error_message`, `created_at` и `updated_at`. В лекции из готового текста путь к аудио пуст. Статусы лекции: `queued`, `processing`, `completed` и `failed`. Состояние генерации конспекта хранится в `notes_state` вместе с версией текста, по которой он создан.

Интерфейс находится в `src/konspekt/ui`. Обработка записи и конспекта соединяется с базой через `pipeline.py`; поиск находится в `search.py`. Работа на отдельном устройстве, аккаунты и синхронизация не входят в настольный выпуск.

Используйте отдельную ветку и Pull Request. Для запуска с отдельной базой задайте `KONSPEKT_DATA_DIR` в окружении. Храните реальные записи, расшифровки и базы вне Git. Проверки GitHub Actions используют тестовые данные и не скачивают модели.
